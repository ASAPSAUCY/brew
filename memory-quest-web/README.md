# Memory Quest — Browser Edition

A cozy top-down adventure (Animal Crossing × Pokémon) about Kyle & Claudia's four years together. No engine, no install, no build — the entire game is one HTML file.

## Play

Open **`index.html`** in any modern browser (double-click it). That's it.

- Works offline — everything (art, music, world, save system) is inside the one file.
- Works on phones/tablets too: left half of the screen is a virtual joystick, tap the right side to interact.
- Progress saves automatically in the browser (Continue on the title screen).

## Controls

| Input | Action |
|---|---|
| WASD / arrows | Move |
| E / Space | Interact, advance dialogue |
| Tab | Scrapbook (team, Memorydex, keepsakes) |
| C | Cycle battle partner |
| M | Toggle music |
| 1–4 | Battle choices |

## The quest

Explore six zones — The Apartment, Hallow Grove, The Courts, Little New York, Montreal Corner, and Cozy Park. Befriend 8 wild memories (battle them with Buddy, then win them over with a treat), collect 6 keepsakes, and the Final Room opens. Solve the pedestal puzzle in the right order to reach the ending.

Say hi to Rumor while you're out there. He's waiting in the park.

## Files

- `index.html` — the complete game (this is the only file you need)
- `part1.html`–`part4.html` — build sources (data/art, engine, gameplay, rendering); concatenating them in order produces `index.html`
